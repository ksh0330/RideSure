## 확인되지 않은 내용

현재 CSV 내부, 기존 README, 코드, 프로젝트 메모에는 아래 근거가 없습니다.

- 원 데이터를 제공한 기관과 정확한 다운로드 URL
- 수집/가공 과정
- 적용 라이선스
- 원본을 GitHub에서 재배포할 수 있는지 여부

따라서 출처와 라이선스 상태는 **미확인**입니다. 공개 배포 또는 공개 GitHub push 전에 데이터 제공 페이지의 이용 약관/공공누리 유형을 확인하고 이 문서에 제공 기관, 원문 URL, 다운로드 날짜, 라이선스, 가공 내역을 기록해야 합니다. 확인 전에는 로컬 커밋 또는 접근이 제한된 Private 저장소에서만 취급합니다.
